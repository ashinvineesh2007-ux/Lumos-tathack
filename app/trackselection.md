Track 2: Safe & Trustworthy AI

Human Abstract:
Generative AI and Retrieval-Augmented Generation (RAG) systems are rapidly being deployed across industries, yet traditional RAG architectures suffer from a critical flaw: document retrieval relies on topical relevance rather than user authorization. When an assistant accesses an enterprise knowledge base through a single privileged connection, low-clearance users can query topics that pull confidential chunks—such as executive compensation, acquisition plans, or internal roadmaps—directly into the LLM context, leading to unauthorized data disclosure, indirect prompt injection exploits, and model hallucinations.
RAGLeak is a lightweight, zero-latency security testing and enforcement engine designed to audit and eliminate authorization bypasses in AI assistants. Operating on a strict fail-closed model, RAGLeak moves the security boundary from fragile system prompts to a deterministic server-side gateway. Before any retrieved text reaches the LLM context window, the system evaluates user identity against document-level Access Control Lists (ACLs) and metadata clearance tiers. RAGLeak includes an interactive auditing environment that contrasts an intentionally leaky baseline against protected execution, providing real-time structured event tracing, leakage rate metrics, and defense against indirect prompt injections without introducing LLM-as-a-judge latency.
